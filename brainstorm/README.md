# Brainstorm

Prompts and idea briefs for AI research papers aimed at **ICLR**, **ICML**, and **NeurIPS** (plus nearby workshops).

Use one markdown file or folder per idea. Start from [`idea-brief.template.md`](idea-brief.template.md) for lightweight singles, or a dedicated folder when the idea is locked.

These briefs feed Denario (`set_data_description`, `set_idea`, or custom prompts). They are not finished papers. **Do not run Denario on an idea until its go/no-go says the week-1 pilot is OK.**
