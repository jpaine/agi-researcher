# Locked idea spine — Minutes and Mandates

**Working title:** Minutes and Mandates: Org-Policy Cards as Escalation Features for Iso-Cost Human+SLM Oversight of Multi-Step Agents

**Primary angle:** Angle 1 — iso-cost oversight (org-policy cards as escalation features under a fixed human-minute + SLM token budget).

**Backup angle (only if primary ablation flat):** Angle 3 — OpenControl-Bench-Lite.

## Locked claim (verbatim)

Under a fixed oversight budget (iso-cost human attention + SLM judge tokens/time), attaching machine-readable **org-policy cards** as structured **escalation features** to a human+SLM oversight stack improves detection of org-policy violations on multi-step agent trajectories relative to iso-cost baselines that use the same human+SLM capacity without those policy-card features.

## Setting (v0)

- Free Nebius SWE-agent multi-step trajectories
- YAML OrgPolicy cards (ten named cards)
- Open-weight judges ≤8B
- Fixed human-minute audit budget
- Budget envelope $0–$20; free data only
- Workshop / short-paper path (MASO → AAAI / ICLR workshops); not main-conf SOTA

## Non-claims

Not Magentic-UI, not Greenblatt/Ctrl-Z, not OCL, not ToolGuard, not One-Human-N, not SCHEME — see `constraints.md`.
